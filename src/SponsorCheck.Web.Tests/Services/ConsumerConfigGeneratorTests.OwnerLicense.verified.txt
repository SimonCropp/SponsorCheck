# Configure SponsorCheck licensing for ThePackage

Generated by the [SponsorCheck setup wizard](https://simoncropp.github.io/SponsorCheck/consumer).

Context: the build references `ThePackage` 1.2.3, which bundles the [SponsorCheck](https://github.com/SimonCropp/SponsorCheck) build-time sponsorship verifier, and requires a license-mode declaration on every build.

- Chosen mode: time-bounded private license
- Placement: owner mode — global MSBuild properties prefixed 'acme_'

## Change to make

File to edit: Directory.Build.props (covers every project under it) — or any one consuming project's .csproj.

Add the properties below to a <PropertyGroup>. One declaration covers every package from owner 'acme'; the property names are exact (the owner prefix is baked into the package).

```xml
<PropertyGroup>
  <acme_SponsorshipLicensedUntil>2027-06</acme_SponsorshipLicensedUntil>
</PropertyGroup>
```

## Expected build outcome

Passes silently through the end of 2027-06 (UTC). After that the build fails with SC025 until the value is renewed — a one-line edit. Values more than one year from the build clock are rejected with SC037.

Notes:

- The properties cover every package from owner 'acme' — one declaration for the whole family. The exact property names are also printed in the SC021 error message.
