# Configure SponsorCheck licensing for ThePackage

Generated by the [SponsorCheck setup wizard](https://simoncropp.github.io/SponsorCheck/consumer).

Context: the build references `ThePackage` 1.2.3, which bundles the [SponsorCheck](https://github.com/SimonCropp/SponsorCheck) build-time sponsorship verifier, and requires a license-mode declaration on every build.

- Chosen mode: time-bounded private license
- Placement: per-package metadata on the <PackageVersion> (Central Package Management)

## Change to make

File to edit: Directory.Packages.props — the file holding the <PackageVersion> items under Central Package Management.

Add the new attribute(s) to the existing <PackageVersion Include="ThePackage"> element — do not create a second element, and do not put the metadata on the <PackageReference>.

```xml
<PackageVersion Include="ThePackage" Version="1.2.3"
                SponsorshipLicensedUntil="2027-06" />
```

## Expected build outcome

Passes silently through the end of 2027-06 (UTC). After that the build fails with SC010 until the value is renewed — a one-line edit. Values more than one year from the build clock are rejected with SC036.

Notes:

- Keep the metadata in exactly one place: on the <PackageVersion>. Setting it on the <PackageReference> as well raises SC019; only on the <PackageReference> raises SC020.
