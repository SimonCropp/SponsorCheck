Mode & scope

An opaque label — give every package in the family the same value (e.g. an org slug). It becomes the consumer-side property prefix, e.g. <acme_GitHubSponsorAccount>.

SponsorCheck adds no runtime dependency — verification happens only during the build. Full documentation in the readme, the consumer guide, and the author guide.
