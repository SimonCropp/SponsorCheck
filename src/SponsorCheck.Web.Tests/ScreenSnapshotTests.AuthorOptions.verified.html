Options all optional

Tune the severity and message of the verifier diagnostics consumers see, define exemptions, or point all sponsor links at one custom page. Leave as-is to use the defaults.

Named carve-outs for consumers who legitimately don't need to sponsor (consulting clients, small businesses, …). Consumers claim one by name; the build warning quotes the criteria text verbatim.

Leave max months blank for an open-ended exemption. Set it and the consumer must also declare SponsorshipExemptionUntil, dated no further out than that — so a claim they stop qualifying for fails the build instead of riding along unnoticed.

When set, every sponsor link in the verifier messages points here instead of the platform pages.

SponsorCheck adds no runtime dependency — verification happens only during the build. Full documentation in the readme, the consumer guide, and the author guide.
